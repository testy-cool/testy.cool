# testy.cool

The public publishing site for testy.cool, combining editorial content, curated directories, and interactive tools.

## Language

**Site UI**:
The shared framing and editorial presentation across navigation, the homepage, posts, directories, the stack, static pages, and tool page shells. It excludes the functional interface inside an individual interactive tool.
_Avoid_: Overall site, site chrome, global UI

**Technical publication**:
The primary identity of testy.cool: an independent publication about LLMs, agents, automation, and development, supported by practical tools.
_Avoid_: Personal portfolio, SaaS product site, tool directory
