Every arrow and label on this page is the library running live. No screenshots,
no JavaScript.

## What it is

[neat-annotations](https://github.com/syabro/neat-annotations) is one CSS file,
8.5 KB, free to use, by Maxim Syabro. You wrap a word in a tag, give it a class
name and a `data-note` with the label text, and it draws a highlighter mark
behind the word, an arrow, and a hand-written label.

<AnnStage>
  <Ann note="the target" dir="n">a word</Ann>
</AnnStage>

The class name is a compass direction, and there are eight of them. The
direction is where the arrow points, so `ann-n` sends the arrow up and parks
the label underneath. That caught me out the first time.

<AnnStage>
  <div className="grid grid-cols-2 gap-x-8 gap-y-40 md:grid-cols-4">
    <span><Ann note="ann-n" dir="n">n</Ann></span>
    <span><Ann note="ann-ne" dir="ne">ne</Ann></span>
    <span><Ann note="ann-e" dir="e">e</Ann></span>
    <span><Ann note="ann-se" dir="se">se</Ann></span>
    <span><Ann note="ann-s" dir="s">s</Ann></span>
    <span><Ann note="ann-sw" dir="sw">sw</Ann></span>
    <span><Ann note="ann-w" dir="w">w</Ann></span>
    <span><Ann note="ann-nw" dir="nw">nw</Ann></span>
  </div>
</AnnStage>

There are six colours, and the highlighter mark can be turned off.

<AnnStage>
  <div className="grid grid-cols-2 gap-x-8 gap-y-24">
    <span>
      <Ann note="a colour" dir="s" color="blue">
        blue
      </Ann>
    </span>
    <span>
      <Ann note="no highlighter" dir="s" noMark>
        plain
      </Ann>
    </span>
  </div>
</AnnStage>

The arrow and the label are drawn by CSS alone, as two extra pieces attached
to the word. Each arrow is a small picture stored inside the CSS file, one per
direction. Nothing runs in the browser.

## Why I tried it

I write posts where I need to point at a specific word or a specific line and
say what it is. Until now that meant taking a screenshot and drawing on it,
which goes stale the moment I edit the sentence. The alternative I knew about
was rough-notation, and that is JavaScript. It has to run in the browser and
measure the word before it can draw anything.

## What I did

I copied the CSS file into this site's code, wrapped it in two small
components, and used it on this page. Here is a real sentence with a real
annotation in it, sitting inside the padded panel I had to build:

<AnnStage>
  The <Ann note="this is the bit I mean" dir="s" color="green">middle part</Ann>{" "}
  of a sentence can carry a label.
</AnnStage>

Seven things I found.

**The labels take up no space.** The page lays out its text as if they were
not there. Each line of text on this site is 28px tall and paragraphs sit 20px
apart. A label with its arrow is taller than that, so inside a normal paragraph
it lands on the line above or below. The instructions say to leave room, and
the project's own demo page does that by hand, with 58px to 200px of empty
space around each example. I made that a component instead, which is why every
annotation above sits inside a bordered panel. The panel is not decoration. It
is the room the label needs.

**The compass name is the arrow, not the label.** `ann-n` points the arrow
north and puts the label south of the target. Obvious once you see it, and the
opposite of what I typed first.

**The marked phrase becomes one solid box.** If the phrase is long enough to
wrap onto a second line, the box covers both lines and the arrow points at the
whole block rather than at a word. Mark short phrases.

**The label text is 15px.** The file sets it as a fraction of the page's base
text size, so if the base size changes, the label follows. That clears my 12px
floor, so I did not have to change it.

**You need a browser from late 2024 or newer.** The file uses four recent CSS
colour features. The newest one, a way to write a colour as a change to another
colour, arrived in Safari 18. That is the oldest browser that shows it right.

**Dark mode works on its own, with one condition.** Each colour has a light
and a dark version and picks one by reading a page setting called
`color-scheme`. That setting has to be present on the marked word or something
around it. My panel sets it.

**The handwriting font is a separate download.** The labels expect a font
called Shantell Sans. Without it they fall back to whatever the computer calls
its `cursive` font, and on my machine that looks nothing like handwriting. I
put a copy of the font next to the CSS file, with its licence, so nothing loads
from Google.

One more thing worth saying out loud. The project has no version numbers. The
link everyone uses always serves the newest copy of the file, so it can change
under you without warning. I copied the file into this site and wrote the date
and the exact version I took at the top of it, so this page keeps working if
the file changes later.

## Verdict

Kept. It does one thing that nothing else does without JavaScript. The cost is
an 8 KB file that only pages with an annotation load. If it ever fails, you see
a plain highlighted word, not a broken page. The catch is that you cannot drop
it into normal paragraphs. Labels need room, so this is a thing I put in a
panel inside a post, not a thing I sprinkle through the text.
